# 한국어 Transformer V2

V2는 기존의 직접 구현한 decoder-only Transformer를 사용하며, 바이트 수준 BPE, 문서 단위 검증 분할, CUDA 혼합 정밀도, 학습률 warmup 및 cosine decay, 학습 재개를 제공합니다. V1 명령은 그대로 사용할 수 있습니다.

## 설치와 데이터

Python 3.11 이상에서 `pip install -r requirements.txt`를 실행합니다. 텍스트 파일은 UTF-8이어야 하며 **한 줄을 한 문서로 처리**합니다. 빈 줄은 건너뛰고, 공백과 Unicode를 정규화한 뒤 중복을 제거합니다. 문서 내용과 seed를 이용해 학습 및 검증으로 분리하므로 동일한 문서는 두 분할에 동시에 들어가지 않습니다. 어느 한 분할이 비면 데이터를 늘려야 합니다. BPE는 학습 문서로만 학습합니다.

로더는 파일 또는 Hugging Face에서 스트리밍하지만, 전처리와 BPE 학습은 선택된 문서 전체를 메모리에 보관합니다. 기본 상한은 10,000문서이며 `--max-documents`로 조정하세요. BPE 구현은 간단한 CPU 구현이므로 대규모 코퍼스에서는 느릴 수 있습니다. 학습 데이터와 토큰, 체크포인트는 Git에 추가하지 마세요. 기존 V1 예제 텍스트 파일은 데이터 제외 정책 때문에 Git 기준 커밋에 포함되지 않습니다.

## 로컬 데이터 학습

```powershell
python -m korean_transformer_v2 train --data C:\data\korean.txt --output checkpoints\korean-v2.pt --device cpu
```

GPU가 사용 가능하면 `--device cuda`를 지정하거나 `--device`를 생략하여 자동 선택합니다. `--precision auto`는 CUDA에서 BF16 지원 시 BF16, 아니면 FP16을 선택하고 CPU에서는 FP32를 사용합니다. 명시적 값은 `fp32`, `fp16`, `bf16`이며 FP16/BF16은 CUDA가 필요합니다. `--gradient-accumulation-steps`로 누적 횟수를 설정할 수 있습니다.

작게 동작을 확인하려면 충분한 양의 문서가 있는 파일로 다음을 실행합니다.

```powershell
python -m korean_transformer_v2 train --data C:\data\korean.txt --output checkpoints\smoke-v2.pt --device cpu --max-steps 10 --warmup-steps 2 --context-length 16 --embedding-dim 32 --num-heads 4 --num-layers 1 --batch-size 2 --eval-batches 1 --checkpoint-interval 5
```

## Hugging Face 데이터

```powershell
python -m korean_transformer_v2 train --dataset 조직명/데이터셋 --text-column text --revision 커밋SHA --max-documents 5000 --output checkpoints\korean-v2.pt
```

`--split`, `--dataset-config`, `--text-column`으로 소스를 선택합니다. 인증은 Hugging Face CLI 로그인 또는 환경의 `HF_TOKEN`을 사용합니다. 프로그램은 토큰을 체크포인트에 저장하지 않습니다. `--revision`에 고정된 커밋 SHA를 지정하면 같은 데이터를 다시 선택하기 쉽습니다.

## 체크포인트와 재개

`--checkpoint-interval`마다 및 정상 종료 시 원자적으로 저장합니다. 갑작스러운 중단 시 마지막 체크포인트 이후 작업은 다시 실행됩니다. 재개 시 원본 문서와 순서가 같아야 합니다. 정규화된 학습·검증 문서의 지문이 다르면 재개를 거부합니다. 모델, 옵티마이저, 스케줄러, 정밀도 스케일러, 난수 상태와 설정을 복원합니다.

```powershell
python -m korean_transformer_v2 train --data C:\data\korean.txt --output checkpoints\korean-v2.pt --resume checkpoints\korean-v2.pt
```

재개 명령은 모델과 학습 설정을 체크포인트에서 읽으므로 새 설정 옵션은 적용하지 않습니다. `max_steps`는 추가 횟수가 아니라 최초에 정한 전체 목표입니다. `--stop-after`는 중간 단계에서 정상 저장하고 종료할 때 사용할 수 있습니다. 다른 기존 체크포인트는 출력 경로로 덮어쓰지 않습니다.

## 생성

```powershell
python -m korean_transformer_v2 generate --checkpoint checkpoints\korean-v2.pt --prompt "안녕하세요" --max-new-tokens 100 --temperature 0.8 --top-k 40
```

`--greedy`는 확률 샘플링 대신 가장 가능성이 높은 토큰을 고릅니다. 학습하지 않은 모델이나 짧게 학습한 모델의 출력 품질은 보장되지 않습니다.

## 테스트

```powershell
python -m pytest -q
```

CPU 테스트는 스트리밍 모의 데이터, 전처리, BPE, 학습, 생성, 체크포인트 및 중단 후 재개를 검증합니다. CUDA 혼합 정밀도의 실제 동작은 CUDA 장치에서 별도로 검증해야 합니다.
